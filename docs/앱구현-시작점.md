## 2. 카드 한 장의 필드
```
id 영구번호 · ids[] 합쳐진 중복 번호 · n 이름 · a 주소
t 구분 0공중 1개방 2간이 3이동   ft 시설 종류(역·공원·주유소·관공서·공공시설 …)
la, lo 좌표 · g 등급 A건물/B필지/P시설  · w 'F'시설위치 'W'넓은곳 'M'산지 · pc 1확인/0추정 · p 카카오 장소ID
h 개방시간 {k:'a'항상|'h'시각|'u'확인필요, r:[[요일비트,'0900','1800']], hd 공휴일, br 쉬는시간, dw 원문이 말한 요일} · ht 원문
m [남 대,소] · f 여 · x [남장애인,여장애인] · c [남어린이,여어린이] · dp 기저귀 · bl 비상벨 · cc CCTV
ni 1=시설 정보 없음 · fq 1=여성 0(공용 의심) · gs 1=주유소 · gt 1=개찰구 안/0=밖 · dy 정보 기준 연도 · o 관리기관 · tel 전화
```

**역 한 곳(`app/data/rail.json` → `s[]`)**
```
n 역명 · ln 노선 · op 운영기관 · src 출처(국가철도공단|서울교통공사) · la, lo 좌표(노선마다 따로)
t[] 화장실: f 층(B1·2F) · g 1=개찰구 안/0=밖 · x 출구('3' 또는 '7·8') · w 자세한 위치(글) · s 남여
   서울교통공사만: m[남 대,소] · fm 여 · ac[장애인 남,여] · ch[어린이 남,여] · dp[기저귀 남,여] · bl · cc · tel · ht · ry 리모델링
renamed 개명표(옛 이름→새 이름) — 저장해 둔 역이 이름만 바뀐 것이면 앱이 이어 준다
```
정렬: **층은 지면에서 가까운 순**(1F·2F·B1·3F·B2…), 같은 층이면 **개찰구 밖 먼저**, 그다음 출구 번호.

## 3. 화면 순서(목업 `design/mockup_mobile_v3.html`)
1. **첫 화면** — 시간대 배경(낮 06~17 `bg_day_blue`, 저녁 17~20 `bg_evening`, 밤 20~06 `bg_night`, 1080px webp) + 제목 "너의 화장실은."(송명 85% + 위쪽 어둡게) + [내 위치로] [다른 곳]
2. **핀 확정** — 지도 가운데 고정 핀, 핀 아래 주소(카카오 좌표→주소), 오차 크면 경고, [여기 맞아요]
3. **목록**(기본) — 기준 위치 바 + 필터 칩(지금 열림·안심·장애인·기저귀·어린이 / 종류) + 카드
4. **지도 보기** — 핀 + 아래 좌우 카드(연동)
5. **상세** — 픽토그램 44px, 개방시간 원문, 관리기관 전화, 길찾기(카카오·네이버 도보)·입구 로드뷰·장소 확인, 기준 연도
6. **알아보기** — 공중화장실 5종·개방화장실·시간 표기·설치 기준·데이터 이야기 + 행안부 링크
7. **없을 때** — 반경 넓히기 → "지금 열림" 끄기 순서로 완화

## 4. 화면 규칙(정한 것)
- **보기 설정(6-8)**: 색은 토큰(`var(--…)`)만, 크기는 **rem**만, 누르는 것은 **44px 이상**. 새 화면은 `어둡게`·`아주 크게`로 한 번씩 확인한다.
- 주 색 **인디고→바이올렛**(`#4338CA→#6D28D9`), 버튼만 그라데이션. 공중=청록 채움 알약, 개방=청록 테두리 알약.
- 위치 정확도 뱃지(C안, 아이콘 알약): 건물·필지는 **뱃지 없음**, `🏢 시설 위치`(636) · `❓ 추정`(375).
- 안내 문구는 사례지식 2-13 표 그대로(시설/추정/넓은 곳/주유소/시간 확인).
- 단어 단위 줄바꿈(`word-break: keep-all`), 알약·칩 4글자 안팎, 이름 한 줄 + 말줄임.
- 픽토그램: 카드 28px·숫자 16px, 상세 44px. 없으면 흐리게, `ni`면 "시설 정보 없음", `fq`면 여성 "?".

## 5. 계산 규칙
- **거리**: 기준점 ↔ 좌표 직선거리, 도보 분 = 거리/67m(분당).
- **지금 열림**: `h`를 휴대폰 시각·요일과 비교(`hours.py` `state`와 같은 규칙). 공휴일은 `holidays.json`. 닫기 30분 전이면 "곧 닫힘".
- **묶음**: 좌표가 같은 카드는 한 핀 — "이 건물 안 N곳".
- **불러오기**: 기준점이 든 칸 + 둘레 8칸. 반경 300m·500m·1km.

## 6. 준비물·주의
- 카카오 지도 JS 키: **착한가격지도 앱의 키를 함께 쓴다.** 무료 쿼터는 **계정당 한 앱**뿐이라 나눌 수 없다(6-37). 새 도메인이 생기면 그 키의 JavaScript SDK 도메인에 추가한다.
- **길찾기는 네이버 도보가 주 버튼**이다. 카카오 `link/to`는 **자동차 경로**로 열린다(6-36) — "자동차 기준"이라고 적어 둔다. 구글 도보는 국내 미지원(6-9)이라 "지도에서 보기"만.
- **지금 위치는 저장하지 않는다.** 사용자가 스스로 담은 것(저장한 곳·최근 본 곳)만 기기에 남기고, 서버로 보내지 않으며 한 번에 지울 수 있다(6-31).
- 출처·면책 문구: "출처 행정안전부 공중화장실정보(공공데이터포털) · 기준일 YYYY-MM-DD / 실제와 다를 수 있습니다 + 공식 오류 신고 링크".
